## What's new

- **Installs with Play Protect on.** Dokusho no longer asks for permission to install other apps.
  Play Protect was blocking v0.1.7 and v0.1.8 because of that permission.
- **Extensions install inside Dokusho.** Browse → Extensions works the same: add your repo,
  tap Install or Update. Extensions are stored inside the app instead of appearing as separate
  apps, and there is no Android install pop-up. Shizuku is still available under
  Settings → Advanced → Extension installer.
- **Updates open in your browser.** When an update is available, Download opens the APK in the
  browser. Open the downloaded file to install it.
- First-run setup no longer has the "Install apps permission" step.

## Good to know when installing

- Extensions installed by an older version may keep working. If one does not show up, uninstall
  it and install it again from Browse → Extensions.
- Clearing Dokusho's data or uninstalling Dokusho also removes its extensions; install them again
  from your repo.
- If the phone still blocks the APK, open Play Store → profile icon → Play Protect → settings and
  turn off **Scan apps with Play Protect** while you install, then turn it back on.
